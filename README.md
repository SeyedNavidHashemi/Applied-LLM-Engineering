# Applied LLM Engineering & Agents Portfolio

A curated collection of mini-projects, experiments, and mini-applications built during my journey through LLM Engineering and Autonomous Agents courses. 

## 🛠 Core Technologies

- **AI/ML:** OpenAI Models, Hugging Face, Vision-Language Models, NLP
- **Frameworks:** LangChain / OpenAI Agents SDK
- **Vector Databases:** ChromaDB
- **UI & Deployment:** Gradio
- **Languages:** Python

## Philosophy
Each sub-folder acts as a standalone mini-project with its own README. High-volume data and vector embeddings are intentionally kept out of this codebase and are hosted separately on [Hugging Face Datasets](https://huggingface.co/NavHash/datasets)).
